# CV Extractor MVP

Мини-сервис для извлечения структурированных данных из текста резюме с помощью LLM.

Цель проекта: показать стек, нужный для стажировки:

- FastAPI
- строгий JSON (Pydantic-схемы)
- нормализация полей (телефон, даты, skills)
- логирование и метрики
- запуск в Docker

## Статус

- Спринт 0: каркас приложения, схемы, health-check ✅
- LLM, нормализация, SQLite, метрики качества — в следующих спринтах.
